# 필터

- **필터 항목은 일정 표기 그대로이고, 셀은 AI 번호의 계층으로 맞춘다.** `10.5.4.1`을 고르면 `10.5.4.x`와 `10.5.4` 셀도 보이고,
  `10.5.4.x`를 고르면 `10.5.4.*` 셀이 모두 보인다.
  - 셀의 범위는 `data-ai-scope`(`renderer.py`의 `_ai_filter_scope`), 필터 항목이 고르는 번호는 `FD.aiIds`(`_ai_ids`)다.
    `10.6.2/10.6.1.1` 같은 슬래시 표기도 번호별로 푼다.
  - `x` 항목은 하위 항목을 모두 덮는다. 맨 번호(`10.5.4`)도 덮지만, 같은 셀에 그 하위 항목이 함께 적혀 있으면 덮지 않는다.
    RAN2는 `8.1, 8.1.2`처럼 상위의 자기 몫을 하위와 나란히 적기 때문이다.
  - 번호끼리 맞출 때 Agenda.csv는 쓰지 않는다. 번호 자체가 트리이고, 회의가 다르거나 파일이 없어도 같은 결과가 나와야 한다.
    AI가 없는 셀에 번호를 붙이는 일은 따로다(`.claude/rules/ran1/agenda-labels.md`).
- **필터와 Agreement 패널은 AI 값을 따로 쓴다.** 필터는 일정 표기 그대로인 `data-ai`, 패널은 하위 섹션까지 푼 `data-agreement-ai`다.
  하나로 합치면 `10.6.x` 같은 필터 항목이 셀과 맞지 않는다.
- **필터는 URL 해시(`#filter=…`)에 있고, 같은 문자열을 `localStorage`에도 둔다.** 헤더의 미팅 링크에는 해시가 없어서,
  다른 WG에 다녀오면 URL만으로는 필터가 사라진다.
  - 키에 `wg_id:meeting_id`가 들어간다(`FILTER_KEY`). WG마다, 회의마다 따로 기억하고 다음 회의로 넘어가지 않는다.
  - URL에 필터가 있으면 URL이 이긴다. 공유받은 링크를 여는 것만으로는 저장된 필터를 덮어쓰지 않고, 필터를 직접 바꿀 때만 저장한다.
  - 저장된 필터를 되살리면 URL에도 다시 적는다. 주소를 복사하면 보이는 화면 그대로 공유된다.
  - Clear는 저장된 필터도 지운다.
