# 셀 클릭 팝업

## 내용

- **순서:** 제목 → Group, Chair, AI 번호, Time, Room → 노트 → AI 이름. 노트가 이 세션에서 실제로 다룰 내용이라 AI 이름보다 위에 둔다.
  텍스트 줄 사이에만 `<br>`을 넣는다(`_join_popup_lines`). 블록 구획 앞뒤에 넣으면 빈 줄이 생긴다.
- **AI 이름은 한 트리다.** 세션의 AI(최하위)는 항상 보이고, 상위 항목은 트리가 길 때만 접힌다.
  - 상위 항목은 공통이면 한 번만 나온다. 번호의 자연 순서로 정렬하면 트리 순서가 된다(`5.1.10`은 `5.1.9` 뒤).
    세션의 AI이면서 다른 AI의 상위인 항목(`15`와 `15.1`)도 AI로 한 번만 나온다.
  - 들여쓰지 않는다. 줄마다 시작 위치가 달라지면 시선을 옮기기 어렵다. 위계는 번호와 크기·굵기로 충분하다
    (상위 항목은 11px 연한 색, AI는 기본 크기에 번호가 굵다).
  - 짧은 트리는 늘 펼친다(`.agenda-open`, 토글 없음): 펼친 줄 수 4줄 이하(`_AGENDA_OPEN_ROWS`)이거나 상위 항목 줄이 1줄 이하.
  - 그 밖의 트리만 접힌다. 펼치기는 팝업에 버튼 하나다(`▸ Show parent items`).
  - `10.6.x` 같은 x 항목은 그 아래 모든 하위 항목을 함께 보이고, 접혀 있어도 항상 보인다.
    트리에서는 x를 떼고 적는다(`10.6.x` → `10.6`, `_agenda_tree_label`). 제목과 `AI:` 줄은 원문 그대로다.
    하위 목록은 RAN1 주석 단계에서 `children`으로 붙인다(`agenda_descriptions.py`의 `_description_hierarchy`; 렌더러에는 의제 표가 없다).
    x 항목 아래에 이미 나온 항목은 따로 한 번 더 보이지 않는다.
  - 펼친 상태는 `.popup-floating`의 클래스(`show-agenda-parents`)로 두어 다음 팝업에도 이어진다.
    `innerHTML`에 두면 같은 셀을 다시 눌러 닫는 비교가 깨진다.

## 위치

- **팝업은 늘 화면 안에 다 보인다.** 위치는 `placePopup`이 정한다(블록 오른쪽 → 왼쪽 → 아래 → 위, 그다음 클램프).
  - 기준은 `window.visualViewport`다. `documentElement.clientHeight`나 `100vh`는 휴대폰 툴바나 핀치 줌 때 보이는 영역보다 커서
    팝업 아래가 툴바 밑에 깔린다. CSS 기본값도 `100dvh`다.
  - 잰 폭을 `width`로 고정한다. 고정하지 않으면 오른쪽 끝 근처에서 브라우저가 팝업을 좁혀 글이 줄바꿈되고 아래가 잘린다.
  - 어느 분기든 가로·세로를 모두 클램프하고, 놓은 뒤 `keepPopupInViewport`로 한 번 더 확인한다.
  - 펼쳐서 높아지면 위쪽 위치는 그대로 두고, 아래가 화면을 넘을 때만 그만큼 올린다.
  - 높이만 바뀌는 resize(휴대폰 툴바)와 `visualViewport`의 resize/scroll(핀치 줌, 이동)은 팝업을 닫지 않고 다시 맞춘다.
    폭이 바뀌면(회전, 창 크기 조절) 그리드가 움직이므로 닫는다.
- **팝업을 조작하다가 닫히지 않게 한다.** 페이지 스크롤은 팝업을 닫으므로, 팝업 위의 휠·터치는 페이지로 넘기지 않는다.
  팝업이 스스로 스크롤될 수 있을 때만 팝업이 움직인다.
