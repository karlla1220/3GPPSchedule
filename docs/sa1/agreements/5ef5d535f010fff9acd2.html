S1-263496

6G WI Rapporteurs

pCR on 6G Computing Service definition

Noted

Revision of S1-263485.

The latest status of the definition will be used as a baseline for further discussiions:

6G Computing Service: a service provided by the 6G network to a subscriber/user or an authorized 3rd party using an application, in order to support the execution of application workloads by using computing related functionalities needed for that application.

NOTE 1: Computing related functionalities use computing resources either from the 6G network (i.e. in Service Hosting Environment), or from authorized 3rd party partners (i.e. outside of 6G network with service level agreement with operator), or from both.

NOTE 2: Examples of application workloads include XR rendering, or other computation-intensive tasks related to an application.

NOTE 3: The application is an application on the UE, or an application hosted within the 6G network (e.g. on an application server) or outside of the 6G network (e.g. on an application server).

NOTE 4: When the 6G Computing Service is provided, it is expected the QoS to be met.

Editor’s Note: Clarification on SHE locations inside of 6G network is FFS, subject to SA2 conclusions.

Editor’s Note: Relationship with AI application workloads is FFS.

Editor’s Note: How to capture the QoS of 6G Computing Service in this definition is FFS.

Editor’s Note: Clarification of computing related functionalities is FFS.

Editor’s Note: Whether to capture computing resources as stated in NOTE 1 in the computing service definition is FFS.
