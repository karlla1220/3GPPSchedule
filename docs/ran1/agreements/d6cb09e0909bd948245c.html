R1-2608524 Feature Lead summary #4 on PDCCH Transmission Schemes Moderator (Nokia)

Observation:

For SU-MIMO operation on 6GR PDCCH, the following evaluation results are observed:

  • For LLS,

    • One source (R1-2607159, CMCC) reported that, with PDCCH CSI acquisition, ideal channel estimation and the same DMRS overhead for both, 2-layer transmission can provide 1~5.1 dB gain for DCI size = 60 bits and 0.6~4.2 dB gain for DCI size = 140 bits compared with 1-layer transmission, with the largest gain at the lowest evaluated AL (AL1 for 60 bits, AL2 for 140 bits);

    • One source (R1-2607343, vivo) reported that, without PDCCH CSI acquisition (codebook-based precoder cycling), 2-layer transmission consistently incurs 0.9~2 dB loss at AL ≥ 2 compared with 1-layer transmission under identical AL and total transmit power for both evaluated delay spreads (CDL-C 100 ns and 300 ns), while at AL1 it provides 0.7 dB gain (100 ns) or incurs 0.26 dB loss (300 ns), for DCI size = 60 bits;

    • One source (R1-2607407, CATT, CICTCI) reported that, compared with single-port precoder cycling at 1% BLER for DCI size = 40 bits with 72 REs (one CCE), 2-port DMRS SU-MIMO with PDCCH CSI acquisition provides 2.15~2.25 dB gain with 2-layer transmission and 3.65 dB gain with rank-1 transmission, while 2-port DMRS SU-MIMO with precoder cycling (without PDCCH CSI acquisition) incurs 2.15~3.15 dB loss.

  • For SLS,

    • One source (R1-2607159, CMCC) reported that, with PDCCH CSI acquisition for both, NW overhead on PDCCH (average number of CCEs per PDCCH) can be decreased by 17%~43% with 2-layer transmission compared with 1-layer transmission, while PDCCH capacity can be enlarged by 1.28~1.88 times (~65/70 → ~90 UEs for DCI size = 60 bits and ~32/40 → ~60/70 UEs for DCI size = 140 bits at 10% PDCCH blocking rate, 4 GHz / 7 GHz).

Observation:

On the UE impact of PDCCH SU-MIMO with multi-port DMRS, at least the following aspects are listed by companies:

  • Additional channel estimation for each additional DMRS port [CMCC, MediaTek, Apple, Qualcomm] and additional memory for buffering and channel estimates [MediaTek].

    • While two sources [CMCC, CATT/CICTCI] report that HW component on multi-port CE/MIMO decoder on PDSCH can be reused.

  • Multi-layer detection instead of single-layer detection [CATT/CICTCI, MediaTek, Apple, Qualcomm]

  • The additional processing applies to every monitored PDCCH candidate [MediaTek, Qualcomm], longer PDCCH processing latency [MediaTek], and potentially additional blind-decoding hypotheses [Qualcomm, Apple] since it is unclear how the transmission configuration is indicated to the UE.

    • While two sources [CMCC, CATT/CICTCI] report that layer information can be informed by UE in advance, so no additional overhead is observed.

  • Additional CSI measurement and feedback for PDCCH [CMCC, MediaTek, Apple, Qualcomm] and difficulty of meeting the 1% PDCCH BLER target with MIMO transmission, even with CSI feedback [Apple]

    • While two sources [CMCC, CATT/CICTCI] report that hardware component on CSI processing/CMR/CSI calculation procedure on PDSCH can be mostly/partly reused.

  • Increased UE power consumption [MediaTek, Apple]

  • A need for inter-layer interference mitigation [MediaTek, Apple]

  • Potential longer scheduling latency for PUSCH/PDSCH and different timelines for different PDCCH MIMO modes [Apple]

Conclusion:

There is no consensus to support SU-MIMO with multi-port DMRS for Rel-21 6GR PDCCH.

Conclusion:

  • There is no consensus to support orthogonal multi-port DMRS for Rel-21 6GR PDCCH MU-MIMO

  • UE-transparent MU-MIMO using non-orthogonal DMRS with a single-port PDCCH DMRS reception is up to network implementation

    • Note: further study of feasibility and necessity of specific ways to enhance UE pairing is not precluded

Agreement:

  • Single-port DMRS-based PDCCH transmission is supported for 6GR PDCCH.

Conclusion:

For the study of 6GR PDCCH transmission precoding schemes:

  • There is no consensus to introduce UE non-transparent transmission precoding schemes for Rel-21 6GR PDCCH.

Agreement:

At least precoding granularity of a single REG bundle is supported for 6GR PDCCH.

Conclusion:

There is no consensus to support modulation orders other than QPSK for Rel-21 6GR PDCCH.
