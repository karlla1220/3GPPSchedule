For studying DL WUS monitoring during active time, the following schemes are considered for performance comparison, e.g., UE energy efficiency gain, UPT, resource overhead, and network complexity:

  • scheme 1: PDCCH skipping during active time

  • scheme 2: SSSG switching during active time

  • scheme 3-1: PDCCH monitoring according to short DRX cycle

  • scheme 3-2: CDRX with long and short DRX cycle enable (where WUS triggers the “onDuration” monitoring)

  • scheme 4-1: C-DRX only

  • scheme 4-2: CDRX with long DRX cycle only (where WUS triggers “onDuration” monitoring).

  • scheme 5: Early termination by DCI/MAC CE

Agreement

For studying DL WUS monitoring during active time, the following schemes are considered for performance comparison, e.g., UE energy efficiency gain, UPT, resource overhead, network complexity:

  • Baseline: PDCCH monitoring according to C-DRX cycle

  • Scheme 0: DL WUS monitoring during active time

  • Scheme 1: PDCCH skipping during active time

  • Scheme 2: SSSG switching during active time

  • Scheme 3: PDCCH monitoring according to shorter C-DRX cycle

  • Scheme 4: Early termination of active time by network indication

  • Scheme 5: DLWUS monitoring +SSSG switching during active time

  • For all schemes, DL WUS monitoring outside active time is assumed.

  • Note: In addition to C-DRX configuration agreed in 6GR power consumption model, companies can report other C-DRX configuration. Companies use the same C-DRX configuration for scheme 0, scheme1, scheme2, scheme 4, and scheme 5.

  • Companies to report the UE behavior after receiving DL-WUS during active time.

  • Note 1: companies are encouraged to provide results for scheme 0 vs scheme 1, scheme 0 vs scheme 2, scheme 0 vs scheme 3, scheme 0 vs scheme 4, scheme 0 vs scheme 5

  • Note 2: companies to report the assumptions of SSSG monitoring periodicity when applicable.

  • Note 3: the study here focus on the performance of DL WUS monitoring during active time
