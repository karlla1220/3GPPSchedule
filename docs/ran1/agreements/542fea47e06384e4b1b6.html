R1-2607513 FL summary #3 for 9.3.1 Ambient IoT R2D design aspects in Rel-20 Moderator (Huawei)

Agreement:

For R2D sequence-based SIP,

  • Device obtains sequence length and M value from periodic broadcast information, the followings are to be further selected

    • Option 1: Periodic broadcast information indicates one sequence length and one M value per RSRP range

      • Opt.1-1: sequence lengths and M values for all configured RSRP ranges are indicated in a given modification period

      • Opt.1-2: one sequence length and one M value for a given RSRP range from all configured RSRP ranges are indicated in a given modification period

    • Option 2: Periodic broadcast information indicates one sequence length and one M value in a given modification period

Agreement:

For L1 R2D control information,

  • Device obtains M value, FEC and repetition from periodic broadcast information, the followings are to be further selected

    • Option 1: Periodic broadcast information provides one value set of {M value, FEC, repetition} per RSRP range

      • Opt.1-1: value sets for {M value, FEC, repetition} for all configured RSRP ranges are provided in a given modification period

      • Opt.1-2: one value set of {M value, FEC, repetition} for a given RSRP range from all configured RSRP ranges are provided in a given modification period

    • Option 2: Periodic broadcast information provides one value set of {M value, FEC, repetition} in a given modification period

    • FFS: whether M value is indicated separately or commonly indicated for sequence-based SIP and L1 R2D control information

The time location of the remaining part of broadcast information (i.e. which first part is followed by the remaining part) is determined based on (part of) broadcast information index, which is indicated in the first part

Agreement:

For R2D unmodulated sinusoid single tone CFO calibration signal, the waveform generation is selected from the followings

  • Option 1: DFT-s-OFDM waveform generation is used to generate unmodulated sinusoid single tone CFO calibration signal

    • FFS: necessary specification change for DFT-s-OFDM waveform generation from Rel-19 includes at least

      • A single subcarrier is used in the existing BB generation exponential in TS 38.291

      • A phase rotation/compensation per OFDM symbol is applied after CP insertion to retain phase continuity cross OFDM symbol boundary

  • Option 2: Waveform generation is up to implementation which needs to retain subcarrier orthogonality of OFDM symbols

    • FFS: how to retain subcarrier orthogonality of OFDM symbols is retained by the followings

      • Define the R2D unmodulated sinusoid single tone CFO calibration signal as Re{β.ej2πf0t} where β is a constant value which is non-related to the modulation symbol and the exact value of β can be up to reader implementation, phase continuity is retained over the time duration of ‘t’

      • The transmission of R2D unmodulated sinusoid single tone CFO calibration start and end both at OFDM symbol boundary
