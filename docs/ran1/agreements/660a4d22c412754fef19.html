Agreement

In FR1 and ~7 GHz, for evaluating serving cell and intra-frequency RRM measurement in both RRC idle and RRC connected by EE processing, assumes the following:

WUS SCS

15kHz for 700MHz; 30 kHz for other frequencies

Channel model

TDL-C, 300 ns delay spread

UE velocity

3km/h, other value is not precluded

PSS/SSS

NR PSS/SSS

Impairment modelling

  • 2 ppm for maximum frequency error Femax before RRM measurement, at least within the same carrier as SSB and the actual frequency error, Fe is modelled as uniform distributions, Fe ~ U [-Femax, Femax] ppm.

  • Sliding window size in time domain for RRM measurement is up to company report.

Number of Tx antennas

1 Tx or single layer

Number of Rx antennas

1, 2

Number of samples for measurement averaging

up to companies’ report, e.g., 1,2,3,4

SNR/SINR

-6 dB/-8.1 dB, other value is not precluded

FFS the SNR for ~7GHz, and extended coverage

Inter-cell interference

3dB higher than measured cell if applied

Measurement cycle

up to companies’ report

  • Note: cell identification/search is not evaluated here
