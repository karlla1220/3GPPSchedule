Agreement

  • At least for UL WUS use cases (if supported) for UEs in idle/inactive mode, 6GR PRACH defined in AI 10.5.1.2 will be selected for UL WUS,

    • Further study whether enhancements are required beyond 6GR PRACH, e.g., considering

      • Robustness with respect to UL synchronization error

      • Detection performance including false alarm rate, missed detection rate, false detection rate, auto/cross correlation properties, etc.

      • Coverage aspect if aNB receives UL WUS with reduced TRxRUs

      • UL WUS sequence that can be shared by UEs in the cell/carrier

      • Detection complexity for BS

      • Implementation complexity for UE

      • Cubic metric/PAPR

      • Number of UL WUS sequences per UL WUS occasion

      • Shared PRACH and UL WUS occasion (impact to PRACH if shared) or separate PRACH and UL WUS occasions.

      • Inter-cell interference

      • UL WUS resource overhead

      • NW/UE energy consumption

Above observations are drawn from the evaluation results assuming that the same SSB periodicity between baseline scheme and proposed OD-SIB1 scheme, and the number of beams is equal to or more than 4.

3 sources (NEC, Tejas, Lenovo) assumed FAR>0% and MDR>0% and other sources assumed ideal UL WUS reception (i.e., FAR=MDR=FDR=0%).

With FAR/FDR higher than 0%, NW may wrongly transmit RAR (if needed) and OD-SIB1, which can consume more NW energy. With MDR higher than 0%, UE may need to retransmit UL WUS, which can consume more UE energy. However, whether the amount of NW/UE energy can be marginally or substantially more is not evaluated.

Note: FAR=0.1% and MDR=1% are assumed for 6GR PRACH for evaluation.
