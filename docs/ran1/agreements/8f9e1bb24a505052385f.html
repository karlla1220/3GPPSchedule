For fixed MCS performance study to allow a single spectrum efficiency point (subject to quantization error) to be supported by multiple (Qm,R) pairs,

  • Detailed observations are captured in Section 3 of R1-2610850.

  • The following approach is used for organizing the detailed observations above.

    • For each case, different company submissions across all channels, MIMO setup, receiver types, etc, are collected for each SE point. The best (Qm, R) pair is identified for each data point (a hysteresis of 0.1dB is applied for numerical stability. For example, only if Qm+2 10% BLER SNR is 0.1dB better than baseline Qm, Qm+2 is declared to win) and the statistics are captured in the tables (Table 1 and Table 2) and figures (Figure 1 and Figure 2). The value of 0.1 dB for hysteresis is assumed for analyzing the LLS output. The exact value for hysteresis is separately discussed.

      • Table 1 is the best (Qm, R) pair count for Qm/Qm-2/Qm+2/Qm+4 across all submission per company and over all configurations. Figure 1 is the best (Qm, R) pair distribution across all companies and across different configurations.

        • The information in the figure is fully captured in the table and may not need to be captured in TR

      • Table 2 is the gain statistics (25%/mean/75%) for Qm-2/Qm+2/Qm+4 for all the cases that Qm-2/Qm+2/Qm+4 is the best (Qm, R) pair (after the hysteresis of 0.1dB) across all companies and across different configurations.

        • The information in the figure is fully captured in the table and may not need to be captured in TR

Observation:

For fixed MCS performance study to allow a single spectrum efficiency point (subject to quantization error) to be supported by multiple (Qm,R) pairs, the following observations are based on evaluation methodology agreed in RAN1-126bis

  • (Qm,R) performance with respect to rank

    • 9 sources (R1-2609598, R1-2609224, R1-2610834, R1-2609307, R1-2609668, R1-2609908, R1-2609356, R1-2610031, R1-2610405) observe that higher-order modulation with lower coding rate outperform the baseline under evaluated high-rank/full-rank, closed-loop fading-MIMO conditions, particularly rank 4 with MMSE reception. Benefits generally become larger or occur at more SE points than in low-rank cases.

    • 2 sources (R1-2610834, R1-2609307) observe that lower-order modulation with higher coding rate outperform the baseline under evaluated high-rank/full-rank, closed-loop fading-MIMO conditions for rML receiver. Benefits generally become larger or occur at more SE points than in low-rank cases.

  • (Qm,R) performance with respect to frequency selectivity

    • 6 sources (R1-2609668, R1-2609908, R1-2610650, R1-2609236, R1-2609408, R1-2609224) observe higher-order modulation with lower coding rate at selected SE points outperform the baseline when sufficient fading/frequency diversity is exploitable. R1-2609408 observes this at lower SE.

    • 1 source (R1-2609236) observes that higher-order modulation with lower coding rate outperforms the baseline when intra-slot frequency hopping is enabled, while it underperforms the baseline when intra-slot frequency hopping is disabled, in evaluated narrowband PUSCH cases.

    • 1 source (R1-2609224) observes that for CP-OFDM, (Qm,R) preference is sensitive to frequency-selectivity. On the other hand, (Qm,R) preference is not sensitive to frequency-selectivity with DFT-s-OFDM.

  • (Qm,R) performance with respect to open loop channel:

    • 6 sources (R1-2609598, R1-2609668, R1-2609908, R1-2609307, R1-2609852, R1-2610465) observe that lower-order modulation with higher coding rate outperforms the baseline under evaluated open-loop configurations, especially when rML receiver is used.

  • (Qm,R) performance for high spatial layer imbalance case assuming NR codeword-to-layer mapping

    • 9 sources (R1-2610465, R1-2609598, R1-2610225, R1-2610553, R1-2609852, R1-2609075, R1-2609908, R1-2610031, R1-2609224) observe higher-order modulation with lower coding rate outperforms the baseline under strong spatial-layer imbalance (such as CDL-A channel with rank 4) within a codeword. Benefits depend on the evaluated conditions and SE points;

    • 2 sources (R1-2609307, R1-2610834) observe lower-order modulation with higher coding rate outperforms the baseline under CDL-A channel with rank 4 within a codeword for rML receiver. Benefits depend on the evaluated conditions and SE points;

  • (Qm,R) performance for spatially balanced case

    • 5 sources (R1-2609852, R1-2609668, R1-2609408, R1-2610553, R1-2609908) observe that lower-order modulation with higher coding rate can outperform baseline at the same SE in cases with balanced spatial layers.

    • 1 source (R1-2610650) observes that the existing NR modulation/code-rate choices are close to optimum in AWGN

    • 2 sources (R1-2609307, R1-2610834) observe that higher-order modulation with lower coding rate can outperform the baseline at the same SE in the case with balanced spatial layers for MMSE receiver.

  • (Qm,R) performance under different receiver type

    • 4 sources (R1-2609307, R1-2610834, R1-2609598, R1-2609224) observe that higher-order modulation with lower coding rate outperforms lower-order modulation with higher coding rate with MMSE under evaluated cases; R1-2609307 and R1-2610834 report higher-modulation/lower-rate gains with MMSE but a preference for lower modulation/higher rate with rML; R1-2609598 reports larger higher-modulation gains with MMSE than with K-best, not necessarily a preference reversal. R1-2610834 specifically associates its receiver contrast with high-rank transmission.

    • 3 sources (R1-2610465, R1-2609598, R1-2609224) observe that lower-order modulation with higher coding rate can outperform baseline with rML receiver under strong inter-layer interference/high-Doppler or open-loop conditions.

    • 3 sources (R1-2609224, R1-2609668, R1-2609908) observe that higher-order modulation with lower coding rate can outperform baseline with both MMSE and rML in evaluated rank-4 fading-MIMO configurations.

  • (Qm,R) performance with respect to MPR (for UL only)

    • 10 sources (R1-2609224, R1-2610834, R1-2609356, R1-2609307, R1-2609598, R1-2609512, R1-2610031, R1-2609668, R1-2610465, R1-2610405) observe that lower-order modulation with higher coding rate outperforms the baseline for selected SE points under UL modulation-dependent power back-off/MPR, especially near modulation transition points.

  • (Qm,R) performance with respect to LDPC code

    • 2 sources (R1-2609307, R1-2610834) report that lower-order modulation with higher coding rate outperforms the baseline and can reduce LDPC decoding complexity at fixed SE, with the evaluated BG3 designs potentially strengthening the associated performance benefit relative to BG1. Higher coding rates reduce decoding-matrix size/active rows, improving decoding throughput or permitting more iterations under the same computational budget.

  • (Qm,R) performance with respect to transmit array size

    • 4 sources (R1-2609598, R1-2609852, R1-2610031, R1-2609224) observe that the higher-modulation advantage is smaller in several evaluated 32Tx4Rx configurations than in 4Tx4Rx configurations.

  • On only selected SE regions need alternative pairs

    • 7 sources (R1-2609598, R1-2609224, R1-2609356, R1-2610834, R1-2609852, R1-2610031, R1-2610225) observe that modulation-transition regions are especially relevant for alternative modulation/code-rate pairs.

  • On commonality of preferred (Qm,R) pairs

    • One source (R1-2609307) observes that the preferred (Qm,R) pairs can be common across different typical fading channels, e.g., the evaluated CDL-A, CDL-B and CDL-C channel.

Agreement:

For performance study to allow a single spectrum efficiency point (subject to quantization error) to be supported by multiple (Qm,R) pairs, to evaluate the performance with 6GR DL codeword to layer mapping, companies are encouraged to provide link level evaluation with link adaptation

  • The evaluation methodology follows agreement in RAN1-126bis

  • For rank>1, use 2 codewords for DL and report for UL.

  • Target 10% first transmission BLER for each codeword. No retransmission in this evaluation

  • Report rank statistics when rank adaptation is on

  • The MCS table(s) supporting one single spectrum efficiency point to be supported by multiple (Qm,R) pairs shall use the set of SE points of current NR (DL 1024QAM table and UL 256QAM table respectively for DL and UL AMC evaluation) as starting point of the evaluation.

  • DL and UL maximum modulation order is 1024QAM

For DL link adaptation evaluation, when reporting results, please use a table form

  • 1st column: SNR (Please use integer SNR points)

  • 2nd column: Achieved spectrum efficiency with NR DL 1024QAM MCS table

  • 3rd column: Achieved spectrum efficiency with a single spectrum efficiency point to be supported by multiple (Qm,R) pairs

For UL, Companies are encouraged to report link level evaluation with link adaption. When reporting results, please use a table form

  • 1st column: SNR (Please use integer SNR points)

  • 2nd column: Achieved spectrum efficiency with NR UL 256QAM MCS table without power backoff adjustment

  • 3rd column: Achieved spectrum efficiency with a single spectrum efficiency point to be supported by multiple (Qm,R) pairs without power backoff adjustment

  • 4th column: Achieved spectrum efficiency with NR UL 256QAM MCS table with power backoff adjustment

  • 5th column: Achieved spectrum efficiency with a single spectrum efficiency point to be supported by multiple (Qm,R) pairs with power backoff adjustment
