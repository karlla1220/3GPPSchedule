Agreement:

On how to indicate the slot offset of PUSCH for aperiodic CSI reporting triggered by a SCell activation command activating the SCell(s),

  • A separate field in the MAC-CE indicates an entry from the configured slot offset list reportSlotOffsetList, and UE ignores the K2 indicated by PUSCH TDRA field in UL grant content.

  • Note: The new field has the same functionality as K2 obtained from TDRA field.

Conclusion:

It is up to RAN2’s design on the condition of whether to send the UE capability signaling in MSG3 or not (e.g., based on MAC layer logical channel prioritization). There is no RAN1 enhancement on the maximum payload size of MSG3.

Agreement:

For a UE transition from IDLE/INACTIVE to CONNECT mode on the SUL, aperiodic SRS-AS triggered by MAC-CE in the MSG4 is not supported.
For a UE transition from IDLE/INACTIVE to CONNECT mode on the normal UL carrier, aperiodic SRS-AS triggered by MAC-CE in the MSG4 shall be on normal UL carrier.

Agreement:

For MSG4-triggered aperiodic TRS with two TRS bursts, the second TRS burst is transmitted in the slot which is a time gap after the last transmission slot of the first TRS burst, where the time gap is configured in a CSI resource configuration provided in the SIBx.

Agreement:

Support close-loop power control (CLPC) for MSG4-triggered SRS when UE transition from IDLE/INACTIVE to CONNECTED mode, and leverage legacy CLPC mechanism, i.e.,

  • The power control adjustment state is determined based on PRACH total power ramp-up and an absolute TPC command indicated via the MAC-CE in MSG4, fb,f,c=∆Prampup,b,f,c+δSRS,b,f,c

Agreement:

Support close-loop power control (CLPC) for MSG4-scheduled PUSCH when UE transition from IDLE/INACTIVE to CONNECTED mode, and reuse legacy CLPC mechanism, i.e.,

  • For PUSCH initial Tx, the power control adjustment state is determined based on PRACH total power ramp-up and an absolute TPC command indicated via the MAC-CE in MSG4, fb,f,c=∆Prampup,b,f,c+δPUSCH,b,f,c

  • For PUSCH Re-Tx scheduled by a DCI format 0_0, the power control adjustment state is determined based on a sum of the accumulated TPC command(s), fb,f,c(i,l)=fb,f,c(0,l)+∑m=1iδPUSCH,b,f,c(m,l) if TPC accumulation is enabled; otherwise, the power control adjustment state is determined based on the absolute TPC command indicated in the DCI, fb,f,c(i,l)=δPUSCH,b,f,c(i,l)

  • Note: The above is based on legacy CSI report configuration(s)

R1-2609216 Moderator summary on enhancing DL CSI acquisition (Round 2) Moderator (MediaTek Inc.)

Agreement:

On MAC-CE triggering indication for early SRS based on a SCell activation command, the SCell activation command MAC-CE indicates a codepoint mapping to an SRS trigger state for each newly activated SCell by the SCell activation command MAC-CE.

  • The SRS trigger state(s) is legacy SRS trigger state(s).

Agreement:

In a SIBx for early CSI-RS/SRS/CSI when UE transition from IDLE/INACTIVE to CONNECTED mode, support the following on the maximum number of resource/report configurations

  • Up to 6 SRS configurations can be configured.

    • Note: As agreed in RAN1#126, up to two SRS resource sets can be configured in an SRS configuration

    • Up to 3 SRS resources can be configured in an SRS resource set

  • Up to 8 CSI report configurations can be configured for PMI-based and/or PMI-free reporting.

    • Up to 8 CSI resource configuration for channel measurement can be configured.

      • Note: As agreed in RAN1#126, only one NZP CSI-RS resource set is provided in a CSI resource configuration for channel measurement

      • Only 1 NZP CSI-RS resource is configured in the NZPCSI-RS resource set.

    • Up to 8 CSI resource configuration for CSI-IM based interference measurement can be configured.

      • Note: As agreed in RAN1#126, only one CSI-IM resource set is provided in a CSI resource configuration for CSI-IM based interference measurement

      • Only 1 CSI-IM resource is configured in the CSI-IM resource set.

    • Note: As agreed in RAN1#122bis, each CSI reporting configuration is associated with a CSI resource configuration for channel measurement and a CSI resource configuration for CSI-IM based interference measurement

  • Note: As agreed in RAN1#123 and RAN#125, up to 1 CSI resource configuration for aperiodic TRS can be configured, and only 1 CSI resource set for tracking is provided in the CSI resource configuration for aperiodic TRS.

Conclusion:

When Rel-20 SRS triggering for SCell switching out of dormancy is enabled, the SRS trigger state indicated in a DCI indicating switching out of dormancy based on legacy DCI formats is applied to the scheduled cell(s) per legacy procedures.

There is no consensus to resolve the following FFS from RAN1#124bis. This conclusion also implies that there is no follow-up specification impact with respect to this FFS:

  • FFS: The cell(s) scheduled by legacy mechanism and configured with aperiodic SRS resource set(s) associated with the SRS trigger state;

Conclusion:

For a UE transition from IDLE/INACTIVE to CONNECT mode, it is upto network implementation to ensure that the MSG4-triggered aperiodic SRS-AS is transmitted on non-SBFD symbols per legacy procedures.
There is no specification.
