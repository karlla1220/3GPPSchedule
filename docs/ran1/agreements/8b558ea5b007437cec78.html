Observation:

When the UE is using a steep-roll-off transmit filter without SE/ST, and where the receiver processing utilizes the knowledge of the transmit filter, the additional gain from non-transparency is typically 0 - 0.5 dB compared to using the same filter, but not utilizing the knowledge of the filter in the receiver processing. In channels with 30ns delay spread and 4 PRB frequency allocation, two sources observed maximum gains of 1.05 and 2.15 dB gains, respectively.

Observation:

Sources reporting benefit of the knowledge of the transmit filter for receiver processing observed higher end of the observed gain range when steep-roll-off transmit filter is used and may depend on the type of receiver processing used.

A steep-roll-off transmit filter is a filter that exhibits roll-off > 14 dB (steeper than allowed by NR Release 15 spectrum flatness requirements for FDSS) relative to its peak.

Note: this observation is applied to both cases with SE/ST and cases without SE/ST.

Observation:

The gain comes at the cost of higher processing burden and/or complexity on the receiver processing, while some companies think that the higher processing burden and/or complexity on the receiver processing is affordable.

Observation:

16QAM with plain FDSS: Relative to 16QAM without spectrum shaping and without CFR, plain FDSS shows a net loss of 2.2–3.6 dB for inner RB allocation and 1.5–2.9 dB for outer RB allocation over SpEff 1.48–2.57, based on two sources; one source additionally reports a 0.2 dB gain at SpEff 2.16 for inner RB allocation. With CFR applied to the reference scheme, a single source reports -0.7 to 0.2 dB over SpEff 1.33–2.57 for inner RB allocation.

Observation:

16QAM compared with QPSK: Against QPSK without spectrum shaping and with CFR, transparent 16QAM with plain FDSS has losses of approximately 0.76 dB, 0.54 dB, and 0.09 dB at SpEff 1.33, 1.48, and 1.70, respectively, while transparent 16QAM with FDSS-SE has losses of approximately 0.80 dB and 0.54 dB at SpEff 1.33 and 1.48. The comparison is based on a single source.

Conclusion:

UL low PAPR enhancement for 16QAM is not pursued.

Proposed conclusion:

  • The same transmit filter is applied to both DMRS symbols and data symbols.

  • It is RAN1 understanding that utilizing the knowledge of the transmit filter in the receiver processing is an implementation choice.

  • It is up to RAN4 how to specify filter characterizations, e.g. by defining the spectrum mask.

  • RAN1 will not define transmit filter coefficients in RAN1.
