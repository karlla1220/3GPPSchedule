R1-2610586 FL summary 1 for 6G channel coding Moderator (ZTE)

Agreement:

For Polar code for DCI with payload size larger than NR range (i.e., larger than 140bits),

  • The maximum mother code length Nmax is 512

    • Option 1-1: Nmax=512, a single segment (i.e., no segmentation)

    • Option 1-2: Nmax=512, up to 2 segments

  • The following options for coding scheme are considered:

    • Option D1: Remove interleaver

    • Option D2: Reuse/Extend D-CRC interleaver

Note: The necessity of DCI payload size larger than NR range needs to be confirmed by other agenda(s)

R1-2610587 FL summary 2 for 6G channel coding Moderator (ZTE)

Observation:

The following provides a high-level summary of companies’ views with respect to drawback of 5G RM code. Note that more information on draw-back or not, and whether it is justifiable or not, can be found in previous observations.

  • Drawback-1-1: 5G RM code suffers from error floor and performance degradation at high code rates (e.g., R>=1/2) due to rank deficiency or limited minimum Hamming distance. This drawback requires enhancements as per the following sources:

12 sources (Xiaomi, vivo, CATT, Tejas, ZTE, Apple, EURECOM, Qualcomm, Google, Jio Platforms, Lenovo, C-DOT)

  • Drawback-1-2: the mother code length of 5G RM code is limited to 32, repetition is needed at low code rates, thus the performance and coverage are degraded. This drawback requires enhancements as per the following sources:

14 sources (Huawei, Xiaomi, CMCC, SEU, vivo, CATT, ZTE, Apple, OPPO, NVIDIA, 1Finity, AccelerComm, CSCN, C-DOT)

  • 5G RM code has no drawback that justifies enhancements

7 sources (Nokia, Samsung, 1Finity, Ofinno, Ericsson, MediaTek, NTT DOCOMO)

R1-2610588 FL summary 3 for 6G channel coding Moderator (ZTE)

Conclusion:

There is no consensus to introduce enhancements for encoding of 3-11 UCI bits as compared to 5G RM code.

For 3-11 UCI bits, 5G RM code is supported.
