    • The transmission of R2D unmodulated sinusoid single tone CFO calibration start and end both at OFDM symbol boundary

  • R2D unmodulated sinusoid single tone CFO calibration signal shall ensure orthogonality with NR OFDM signals

    • RAN1 assumes detail values of Device ID and (one or multiple) pre-defined ID are up to RAN2

Agreement:

From device perspective, for the non-periodic D2R transmission, RAN1 select the following for potential collision handling with periodic R2D transmission

  • For device C: Device assumes to transmit non-periodic D2R transmission if it collides with the reception of periodic R2D transmission, and device skips the reception of at least the collision part of the periodic R2D transmission

    • The determination of the collision part includes switching time between R2D reception and D2R transmission and between D2R transmission and R2D reception

      • Detail value of switching time is up to RAN4

  • For device 2b: Device assumes non-periodic D2R transmission does not collide with the reception of periodic R2D transmission

Agreement:

  • For periodic R2D transmission,

    • When the generated number of chips for the L1 R2D control information does not fully occupy the last OFDM symbol, padding is used

    • When the generated number of chips for the subsequent data payload (scheduled by L1 R2D control information) does not fully occupy the last OFDM symbol, padding is used
