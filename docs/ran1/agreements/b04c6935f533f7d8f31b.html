For PDRCH scrambling sequence initialization, define cinit=NAS−ID×210+Nphysical, where NAS−ID denotes the AS-ID and Nphysical denotes the physical layer reader ID in the range of 0 to 1007. NAS−ID is set to 0 for Msg1 in CBRA and first D2R transmission for DO-A to start DO-A traffic transmission.

Agreement:

For D2R block-level repetition, support Alt 2: {1, 2, 4, 8, 16}.

Agreement:

Support Alt 2-3 for the PDRCH preamble length set:

  • Preamble lengths {7, 31, 63, 127} are supported for OOK.

  • Preamble lengths {31, 63, 127, 255} are supported for BPSK.

Agreement:

For Rel-20 D2R preamble, the preamble sequence index n (0, 1, or 2) is determined as n = Nphysical mod 3, where Nphysical is the current physical layer reader ID.

Agreement:

For D2R midamble structure Option 2 for BPSK, support Alt 1, i.e., use the D2R preamble sequence of the same D2R transmission as base sequence of D2R midamble sequence.

Agreement:

For D2R midamble structure Option 1 for BPSK, m-sequence is supported as the sequence type (i.e., Alt 1).

Agreement:

For Rel-20 D2R transmission, support Option 4 with the following bit duration sets:

  • For Device 2b: {266.67, 133.33, 66.67, 33.33, 16.67, 8.33, 4.17, 1.39} μs.

  • For Device C: {266.67, 133.33, 66.67, 33.33, 16.67, 8.33, 4.17, 2.78} μs.

Agreement:

For the Option 1 and Option 2 midamble structures for BPSK, down select from following alternatives:

  • Alt 1:

    • Step 1: Determine the Option 2 insertion positions based only on data bits and insert the Option 2 midamble bits.

    • Step 2: Determine the Option 1 insertion positions based only on data bits, using the Option 1 insertion interval. If an Option 1 insertion position coincides with an Option 2 insertion position, apply one of the following:

      • Replace the Option 2 midamble bit at that position with the Option 1 midamble.

  • Alt 2:

    • Step 1: Determine the Option 2 insertion positions based only on data bits and insert the Option 2 midamble bits.

    • Step 2: Determine the Option 1 insertion positions by counting both data bits and the inserted Option 2 midamble bits, using the Option 1 insertion interval, and insert the Option 1 midambles at these positions.

Agreement:

For the D2R midamble at the end of PDRCH with BPSK, the following is supported:

  • Indication of structure of D2R midamble at the end of PDRCH

    • The structure of D2R midamble at the end of PDRCH is predefined.

  • Structure of D2R midamble at the end of PDRCH

    • When a D2R midamble at the end of PDRCH is present,

      • The Option 1 midamble is appended at the end of the PDRCH.

  • Applicability of presence indication for D2R midamble at the end of PDRCH

    • The reader indicates presence of D2R midamble at the end of PDRCH using a 1-bit field only when Option 1 is enabled.
