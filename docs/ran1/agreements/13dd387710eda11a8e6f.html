Agreement:

For R2D periodic transmission of broadcast information,

  • The first part and the remaining part of broadcast information have separate CRC

Agreement:

For R2D periodic transmission of broadcast information, the following transmission parameters for the first part of broadcast information are pre-defined as

  • M value is 2

  • FEC code rate is 1/3

  • Repetition number is 4

Agreement:

    • FFS: details of the reduced TBS value set and indication

R1-2607512 FL summary #2 for 9.3.1 Ambient IoT R2D design aspects in Rel-20 Moderator (Huawei)

Agreement:

For R2D, for the transmission of periodic unmodulated sinusoid single tone CFO calibration signal

  • The periodicity is

    • Option P1: same as the pre-defined transmission periodicity (Psync) of R2D periodic sync signal

Agreement:

For R2D, for the transmission of periodic unmodulated sinusoid single tone CFO calibration signal

  • The time location(s) is immediately after a first part of periodic broadcast information transmission including padding if any (when the first part is not followed by a remaining part), or immediately after a remaining part of periodic broadcast information transmission including padding if any (when a first part is followed by the remaining part)

Proposal:

For R2D sequence-based SIP,

  • Device obtains sequence length and M value from periodic broadcast information, the followings are to be further selected

    • Option 1: Periodic broadcast information indicates one sequence length and one M value per RSRP range

      • Opt.1-1: sequence lengths and M values for all configured RSRP ranges are indicated in a given modification period

      • Opt.1-2: one sequence length and one M value for a given RSRP range are indicated in a given modification period

    • Option 2: Periodic broadcast information indicates one sequence length and one M value in a given modification period
